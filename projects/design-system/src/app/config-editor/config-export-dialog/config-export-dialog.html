src/app/app.config.ts

Component defaults, provided through SHIP_CONFIG .

src/styles.scss

Palettes through $shipPalettes , the colours, variants and skins you kept; font, density, radius and border width as custom properties.

ship-config.json

The same settings as data. Import it in this editor to pick up where you left off; npx ship-styles turns its styles into the @use block above.
