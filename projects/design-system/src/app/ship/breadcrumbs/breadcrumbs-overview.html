sh-breadcrumbs shows where the current page sits in the app. Put the crumbs in as direct children — links, buttons or a plain span , optionally with an sh-icon — and separators are drawn between them. The last crumb is styled as the current page; mark it aria-current="page" .

The base style is headless: just type, color and separators, so it fits anywhere. Use variant="type-b" for a boxed surface or variant="type-c" for pill crumbs, and set a project default with {{ '{' }} breadcrumbs: {{ '{' }} variant: 'type-b' {{ '}' }} {{ '}' }} in ShipConfig . Inside an sh-lo-page it lands in the page's nav area automatically.
