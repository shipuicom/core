sh-chat is a single chat message. Slot the parts in — an sh-avatar , the sender in a b , a time , the message itself, and sh-chip s or an element marked footer for reactions and read receipts — and it lays them out as a bubble. Set outgoing on the current user's messages and continued on follow-ups from the same sender (leave out their avatar and name) to group them. typing swaps the content for a typing indicator.

It's only the message: stack them in any container and combine them with the rest of the kit — an sh-divider for dates, an sh-form-field as the composer, an sh-card around it all. The base style is a filled bubble; use variant="type-b" for outlined bubbles or variant="type-c" for flat team-chat rows, and set a project default with {{ '{' }} chat: {{ '{' }} variant: 'type-b' {{ '}' }} {{ '}' }} in ShipConfig .
