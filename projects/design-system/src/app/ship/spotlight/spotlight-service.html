ShipSpotlightService

ShipSpotlightService integrates the spotlight into your application. By default it registers a global Cmd + K (macOS) / Ctrl + K (Windows/Linux) listener that opens the spotlight overlay with every registered item. It also exposes imperative open() and the globalItemSelected signal for handling selections.

Registering items

registerItems() adds items that appear whenever the spotlight opens. It returns a cleanup function to unregister them — and when called from an injection context, cleanup runs automatically when the registering component is destroyed.

Shortcuts: each item can carry an optional shortcut (e.g. "alt+t") that triggers it while the spotlight is open. Avoid reserved browser hotkeys such as Cmd+N, Cmd+T or Cmd+W — browsers block preventing these, and the component throws if you try to register one.

Contextual items

setContextualItems() maintains a single per-context registry — each call replaces the previous contextual set, which makes it ideal for route- or view-specific actions. clearContextualItems() removes them.

Opening imperatively

open() shows the spotlight on demand and returns a ShipSpotlightInstance with itemSelected / closed outputs and a close() handle. Use enableGlobalShortcuts() / disableGlobalShortcuts() to control the global listener at runtime (state is exposed on isShortcutsEnabled).
