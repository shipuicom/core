sh-avatar shows a picture when src loads and otherwise one or two initials taken from name (first and last word). The background colour is derived from the name, so the same person always gets the same colour; set color to use a semantic scale instead. Sizes are small and the regular size.

sh-avatar-group stacks its avatars and folds everything past max into a +N badge. The ring attribute draws an activity ring for states such as "is dragging" or "is editing", and the host takes shTooltip like any other element.
