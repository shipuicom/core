Sheet

Overview

<sh-sheet-view> is the read-only sheet surface: a columnar cell model in, a two-axis virtualized grid out. Both axes run on the shared BlockHeightMap from @ship-ui/core/ship-virtual-scroll — the same pixel model that windows sh-editor blocks and sh-code lines. Selection is a rectangle, copy-out writes TSV and <table> clipboard flavors, and the document form is a real semantic table.
