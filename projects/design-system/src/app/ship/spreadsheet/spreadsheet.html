Spreadsheet

Overview

<sh-spreadsheet> is the read-only spreadsheet surface: a columnar cell model in, a two-axis virtualized grid out. Both axes run on the shared ShipVirtualWindow from @ship-ui/core/ship-virtual-scroll — the same engine that windows sh-editor blocks and sh-code lines. Selection is a rectangle, copy-out writes TSV and <table> clipboard flavors, and the document form is a real semantic table.

Not there yet

The surface is display-and-copy only for now. Missing, in rough priority order:

  • Cell editing — no editable composer yet; the model is immutable in, immutable out.
  • Keyboard navigation — selection is mouse-only; arrow-key roving and Shift+arrow range extension are not wired up.
  • Resizable columns and rows — the model already carries explicit colWidths/rowHeights (see set-col-width / set-row-height ops), but there is no drag-to-resize UI.
  • Paste into an existing spreadsheet — pasting a table materializes a new editor block; in-place range paste is not supported.
  • Formulas — cells are plain strings; no computed cells or references.
  • Formatting, sorting, merged cells, frozen panes beyond the built-in header rails.
