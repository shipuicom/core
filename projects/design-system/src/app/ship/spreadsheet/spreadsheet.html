Spreadsheet

Overview

<sh-spreadsheet> is the read-only spreadsheet surface: a columnar cell model in, a two-axis virtualized grid out. Both axes run on the shared ShipVirtualWindow from @ship-ui/core/ship-virtual-scroll — the same engine that windows sh-editor blocks and sh-code lines. Selection is a rectangle, copy-out writes TSV and <table> clipboard flavors, and the document form is a real semantic table.

Editing

editable turns the same surface into the composer: typing, Enter, or F2 open an in-cell editor over the active cell; Enter/Tab commit and move, Escape cancels; arrows, Shift+arrows, Home/End, PageUp/Down move and extend the selection; Delete clears; paste fills from TSV or a <table> and grows the grid; right-click opens row/column structure; drag a header boundary to resize; Cmd/Ctrl+Z walks the history. Every change is emitted as a SheetOp[] transaction through (ops) and written back to the two-way [(sheet)]; applyRemote(ops) merges concurrent changes and rebases the history over them with transformSheetOps.

Not there yet

Missing, in rough priority order:

  • Cross-sheet references — formulas see one sheet; Sheet2!A1 needs a workbook.
  • Formatting, sorting, merged cells, frozen panes beyond the built-in header rails.
  • Fill handle and drag-move of a range.

The column rail carries the field labels (headers) and the row-number rail is off (letters); Sprint 12 and Backlog are group rows (rowKind) — one band, read-only — and a done record is dimmed through rowClass. Status and Priority are select columns (status, priority): each cell is a real sh-chip drawn by the type's renderer component — one instance per visible cell, re-fed as you scroll.
