Table Content Component

Project the <sh-table-content> component inside <sh-table> to automatically generate columns, headers, and cell rows based on a configuration schema.

Column Config Types

Define column schemas using ShipTableColumn objects. Set the type field to enable out-of-the-box sorting and formatting for: 'string', 'number', 'date', 'boolean', and 'badge'.

Formatting & Rendering

Customize cell rendering dynamically. Provide a cell function for inline string values, a format function for formatting value keys, or a TemplateRef via cellTemplate for complete HTML markup override.

Features & Stickiness

Support features like Sorting and Resizing directly via configuration attributes: sortable, resizable, minWidth, maxWidth, and sticky: 'start' | 'end'.

Accessibility (WCAG)

Support screen reader navigation and labeling. Bind an accessible name to the table container with [aria-label] or [aria-labelledby]. Identify columns uniquely by setting rowHeader: true in the column configuration, which renders cell rows using the semantic role="rowheader" instead of role="cell".
