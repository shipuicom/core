Collapsed

Add the collapsed class to sh-list to animate it down to an icon-only rail: the list narrows to --list-collapsed-w and item labels fade out, leaving the leading sh-icon visible. Toggle the class to animate between the two states.

Items

Every direct child of sh-list is a list item by default. Inherently interactive elements ( a , button , label , or anything with a value attribute) automatically get action affordances. The item and action attributes still work as explicit overrides, and raw opts a child out of item styling entirely.

Selection

Set listRole="listbox" to opt in to selection: two-way bind [(value)] , give items value attributes, and the list handles click/keyboard selection, roving focus, and aria-selected stamping. Use closable to allow deselecting the active item. The default listRole="list" leaves projected content completely untouched.

Suffix

Add the suffix attribute to an element inside a list item to align it to the trailing end of the item.
