ShipThemeState

ShipThemeState is the root-provided service behind sh-theme-toggle. It owns the current theme as a read-only signal, applies the light/dark class on <html> through an effect, and persists the choice to localStorage (SSR-safe — storage access is skipped on the server).

Avoiding the theme flash

With no stored choice the page follows the OS preference instantly through color-scheme and light-dark(), nothing to do. A stored 'dark'/'light' choice, however, is only applied once Angular has bootstrapped, so on a cold reload (or a prerendered page) the browser paints the system theme first and then swaps.
