Public sub-components that compose sh-tree.

Inputs

Name Type Default Description
[(items)] any[] [] Two-way model of flat nodes representing the tree structure.
[sortableManager] TreeSortableManager null Optional manager to enable drag-and-drop tree reordering.
[(selectedId)] string | null null Two-way model of the currently selected node's ID.
[getId] (item) => string (item) => item.id Function mapping a node to its unique ID.
[getName] (item) => string (item) => item.name Function mapping a node to its display name.
[getParentId] (item) => string | null (item) => item.parentId Function mapping a node to its parent ID.
[isFolder] (item) => boolean (item) => item.type === 'dir' Function mapping a node to its folder/dir check.
[getIsOpen] (item) => boolean (item) => item.isOpen Function mapping a node to its folder open state.
[getIcon] (item) => string | null () => null Function returning a custom icon name for a node.

Projected Elements

You can configure default folder and file icons by projecting <sh-icon> elements with specific attributes:

Element Attribute Description
<sh-icon openIcon> openIcon Icon name to display for open folder/dir nodes (e.g. folder-open).
<sh-icon closedIcon> closedIcon Icon name to display for closed folder/dir nodes (e.g. folder).
<sh-icon itemIcon> itemIcon Icon name to display for file/item nodes (e.g. file-text).

Outputs

Name Type Description
nodeClick EventEmitter<any> Emits when a node is clicked (except on folder caret toggles).
nodeToggle EventEmitter<{{ '{' }} node: any, isOpen: boolean {{ '}' }}> Emits when a folder caret toggle is clicked.
