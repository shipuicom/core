ShipDialogService

ShipDialogService is provided in root and opens any component or ng-template inside a ShipDialog overlay — no dialog markup needed in your template. It returns an instance handle with the rendered component, an imperative close() and a closed output.

Opening a component

Pass a component class to open(). When the component declares a data input and a closed output, the service infers their types — data is type-checked against the component's input and the closed callback receives the emitted result.

Opening a template

A TemplateRef works too. The template context exposes the passed data as $implicit and a close function that resolves the closed callback.
