Overview

<sh-window-manager> arranges a set of shWindow panes according to its mode — the basis of an in-browser window manager. Declare each window on an <ng-template> with an id, title, and icon, and the manager renders them where they belong.

Modes

Switch the layout strategy with the mode input:

  • tabs — browser-style tabs; one window visible at a time.
  • grid — a locked tiling grid; drag the gutters between panes to resize.
  • grid-move — the same grid, but drag a tab onto another pane to rearrange.
  • dock — the full layout; drag a tab onto another pane's edge to split, or its centre to merge into a tab group.

Resizing

In every tiling mode, the boundaries between panes are draggable gutters that reapportion the adjacent grid tracks. The smallest a pane can shrink to is set by minFraction .

Tabs

Each region is a tab group. Click a tab to focus its window, or close it with the × (toggle with closable ). Emptied regions collapse and the layout simplifies automatically.
