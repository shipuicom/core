Overview

<sh-editor> is a signal-based, zoneless WYSIWYG editor with a clean separation between the DOM, the AST (Abstract Syntax Tree) and behaviors. The AST is the source of truth: edits flow through beforeinput into an undoable engine transaction and the DOM is re-projected from the AST. It binds two-way via ControlValueAccessor and serializes to HTML, Markdown or JSON.

Architecture

  • Behavior-driven: each block/mark is a standalone behavior class; extend via [behaviors].
  • AST as source of truth: the DOM is a pure projection, so undo/redo and serialization are exact.
  • Signal-based & zoneless: reactive state throughout, no zone.js.
  • Dependency-free: no Prosemirror or Quill.

Basic usage

Import the editor and (optionally) the composable toolbar pieces, then bind [(value)].

Inputs

  • value — two-way ([(value)]); the content as a string or AST, per format.
  • format — 'html' | 'json' | 'markdown' (default 'html'); the serialized shape of value.
  • variant — 'base' | 'document'; 'document' renders a centered page canvas.
  • readonly, placeholder, showMetrics — disable editing, ghost text, word/character footer.
  • behaviors — extra block/inline behavior classes (BaseBlockBehavior / BaseInlineBehavior).
  • sanitize — SanitizeOption; scrub untrusted HTML against the allow-list (or extend it).
  • imageUpload — (file) => Promise<string>; resolve a picked file to its URL.
  • imageEdgeResize — opt in to the image mid-edge (one-axis) resize handles.
  • contextualActions, slashCommands — consumer-provided block actions and slash-menu entries.

Composition

The editor exports as shEditor. Compose a toolbar with <sh-editor-toolbar> + [shEditorAction] buttons (inside the editor, or elsewhere via [editor]), and a selection bubble with <sh-editor-floating-toolbar>.

Variants

Like every Ship component, the editor takes a variant. variant="document" converts the surface into a Google-Docs-style page canvas (a centered, width-constrained page on a muted desk). The default 'base' is the inline surface. The active state is a subtle neutral border on the outer edge.

Theming

The editor is themed with CSS custom properties on sh-editor (e.g. --editor-bg, --editor-border-color, --editor-border-focus, --editor-p, --editor-min-h). Override them to restyle the surface, or switch light/dark automatically via the Ship base/primary scales.
