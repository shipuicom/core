Document Canvas

This editor loads 5,000 blocks up front — headings, both list kinds, code blocks, quotes, callouts, images, horizontal rules, and paragraphs full of inline marks (bold, links, colors, highlight). Past 1,000 top-level blocks the editor virtualizes the viewport: only the blocks in and around the visible area exist in the DOM (~50 elements), with spacer padding standing in for the rest — so load time, typing and Enter stay flat no matter how long the document grows. Scroll the panel below; select-all + copy still serializes the entire document from the model.
