Variants

Like every Ship component, the editor takes a variant. variant="document" converts the surface into a Google-Docs-style page canvas (a centered, width-constrained page on a muted desk). The default 'base' is the inline surface. The active state is a subtle neutral border on the outer edge.

Theming

The editor is themed with CSS custom properties on sh-editor (e.g. --editor-bg, --editor-border-color, --editor-border-focus, --editor-p, --editor-min-h). Override them to restyle the surface, or switch light/dark automatically via the Ship base/primary scales.
