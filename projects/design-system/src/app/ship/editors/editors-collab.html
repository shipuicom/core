Collaborative editing

The editor's operation model is collaboration-ready: every edit is a serializable EditorOp, remote ops are applied with engine.applyRemoteOperation (which maps your caret and keeps remote edits out of your undo history), and concurrent edits converge through transformOp/rebaseOp — the same fuzz-verified algebra the nightly rebase fuzz exercises.

@ship-ui/core/ship-editor-collab packages this into three pieces: ShipEditorCollab (the session service), the CollabTransport interface, and <sh-editor-remote-cursors> (peer carets and selections). The built-in BroadcastChannelTransport syncs same-origin windows with no server — exact for two peers; production multi-peer setups should implement CollabTransport over a server relay that assigns a total order.

Try it:
  1. Click Open second window and place the windows side by side.
  2. Type in either window — edits and the colored remote caret appear live in the other.
  3. Flip on Fuzz edits here, then keep typing in the other window while random edits storm this one. When the checksums in both windows match, the documents converged.

Custom transports

Any ordered-per-sender message pipe works. A minimal WebSocket transport: 

class WsTransport implements CollabTransport {
  #ws = new WebSocket('wss://example.dev/doc/42');
  connected = signal(false);
  constructor() {
    this.#ws.onopen = () => this.connected.set(true);
    this.#ws.onclose = () => this.connected.set(false);
  }
  send(message: CollabMessage) { this.#ws.send(JSON.stringify(message)); }
  subscribe(cb: (m: CollabMessage) => void) {
    const h = (e: MessageEvent) => cb(JSON.parse(e.data));
    this.#ws.addEventListener('message', h);
    return () => this.#ws.removeEventListener('message', h);
  }
  destroy() { this.#ws.close(); }
}

Wire-up is the same regardless of transport: 

@Component({ providers: [ShipEditorCollab], ... })
class DocPage {
  collab = inject(ShipEditorCollab);
  editor = viewChild<ShipEditor>('editor');
  constructor() {
    afterNextRender(() => this.collab.attach(this.editor()!.engine, {
      transport: new BroadcastChannelTransport('my-doc'),
      presence: { name: 'Ada', color: '#e0533d' },
    }));
  }
}
