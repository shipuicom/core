ShipA11yKeybindingsService

ShipA11yKeybindingsService is the root-provided registry behind every keyboard interaction in ShipUI. Actions are named ('spotlight.open', 'datepicker.next-month', …) and mapped to shortcut strings; components ask the service whether a KeyboardEvent matches an action instead of hard-coding keys. You can reuse it for your own components and remap any binding app-wide.

Overriding default bindings

Provide SHIP_A11Y_KEYBINDINGS_OVERRIDE to replace the defaults for any action. The ctrlOrCmd modifier resolves to Cmd on macOS and Ctrl elsewhere, and a comma-separated string registers multiple shortcuts for one action.

Pausing and disabling

pause() / resume() temporarily suspend matching (reference-counted, reflected in the isPaused signal). The isDisabled signal reflects a global kill-switch for all keybinding handling.
