Built in

  • BroadcastChannelTransport — windows of one browser, no server. Any plain string.
  • WebSocketTransport — a relay. Any ws:// or wss:// URL. See the Relay tab.

Your own transport

  • send — deliver to every other peer. Queue while disconnected.
  • subscribe — call back with each peer's messages in the order sent. Return an unsubscribe.
  • connected — read once at attach. Informational.
  • destroy — optional. Called only for transports created from a string.

Per-sender order is enough for two peers. Three or more need one arrival order for all senders — a relay, a broker topic, a single server.

Example

An in-memory hub as a service. Provided on the component, it destroys its transports when the component goes.
