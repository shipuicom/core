shCollab directive

Selector sh-editor[shCollab] , exportAs: 'shCollab' .

Input Type Description
shCollab string | CollabTransport Required. Channel name (BroadcastChannel), ws(s):// relay URL (WebSocket), or a transport instance. Transports created from a string are destroyed with the editor.
presence {{ '{' }} name: string; color: string {{ '}' }} Shown on this peer's caret in other windows. Defaults to Anonymous in grey.
clientId string Stable identity for this window. Generated when omitted.
remoteCursors boolean Default true . Set false to skip mounting the cursor overlay.

The directive exposes the session as collab for templates:

ShipEditorCollab service

Member Description
attach(engine, options) Join a session: transport (required), presence , clientId , presenceThrottleMs (default 100).
detach() Leave the session and stop listening. Also runs on destroy.
peers Signal<ReadonlyMap<string, CollabPresence>> — other peers' name, color and selection.
connected Signal<boolean> — the transport's state at attach.
clientId This peer's identity.
flushLocal() Broadcast pending local changes now. Only needed outside Angular's effect scheduler (tests, custom drivers).
