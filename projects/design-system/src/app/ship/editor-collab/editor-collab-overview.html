Overview

@ship-ui/core/ship-editor-collab makes an sh-editor a shared document. Edits are ops, concurrent ops are rebased, remote edits stay out of your undo history.

Quick start

A channel name shares between same-origin windows. A ws:// URL goes through a relay.

Live demo

Try it
  1. Type in either editor — the other follows, with a colored remote caret.
  2. Turn on Fuzz edits , type in the right editor. Matching checksums mean convergence.
  3. Open a second window — it joins the same document.

In the source, the editor line is the integration. Everything else is demo chrome.

How it works

  • Session — shCollab provides ShipEditorCollab and attaches it to the editor after first render.
  • Ops — each local edit is broadcast with a sequence number and what the sender has seen.
  • Convergence — incoming ops are rebased over unseen local ops, then applied without touching your undo stack.
  • Presence — selections ride along with ops; the directive paints them as remote carets.
  • Late join — a new window asks for a snapshot; any peer answers.
