Overview

@ship-ui/core/ship-editor-collab turns any sh-editor into a shared document. It builds on the editor's operation model: every edit is a serializable op, concurrent edits converge through the fuzz-verified transformOp / rebaseOp algebra, and remote edits never enter your local undo history.

  • shCollab — one attribute on sh-editor : provides the session, attaches it, mounts the cursor overlay and tears it all down with the editor.
  • ShipEditorCollab — the session: broadcasts your edits, rebases and applies everyone else's.
  • CollabTransport — any message pipe; BroadcastChannelTransport (same-origin windows, no server) and WebSocketTransport (server relay) ship built in.
  • <sh-editor-remote-cursors> — peer carets, selections and name tags.

Behavior guarantees

Undo only ever removes your edits; late joiners receive a snapshot from an existing peer; and the op algebra ( transformOp , rebaseOp , applyOp ) is exported for integrations that need to rebase server-side.
