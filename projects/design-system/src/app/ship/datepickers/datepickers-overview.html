Selection

Selected values are available via date and endDate . Use [(date)] and [(endDate)] for two-way binding.

Configuration

Customize the picker behavior:

  • asRange : Enable range selection mode.
  • monthsToShow : Set the number of months displayed (default: 1).
  • startOfWeek : Specify the first day of the week (0-6).
  • weekdayLabels : Provide custom labels for week days.

Input Display

Customize how dates appear in inputs:

  • masking : Set the date format mask (e.g., 'mediumDate' ).
  • size : Use the small attribute/class for a compact input.

Interaction

  • closed : Event emitted when the picker is dismissed.
  • disabled : Standard attribute to disable interaction.

Local Time & Timezones

The datepicker operates using standard native JavaScript Date objects, so it automatically adapts to the user's operating system timezone.

Testing different timezones: Because it relies on the browser's native timezone API, you cannot spoof the timezone programmatically within the component. To test how the datepicker looks and behaves in other regions, use your browser's Developer Tools. In Chrome or Edge, open DevTools, press Esc to bring up the bottom drawer, find the Sensors tab, and change the Location override to a different city (e.g., Tokyo or London).
