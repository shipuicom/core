Code Editor

Overview

<sh-code> is a lightweight code editing surface — between a <textarea> and an IDE. It shares its architecture with <sh-editor>: the document is a columnar line store with a prefix-sum index, the selection is a flat {anchor, head} offset pair, and the viewport virtualizes through the shared BlockHeightMap from @ship-ui/core/ship-virtual-scroll — without pulling any ship-editor code into your bundle.

Read Only Line Numbers

{{ bigLineCount() }} lines in the model — only the viewport's window exists in the DOM. Scroll, jump with ctrl/cmd+End, and edit anywhere.
