Featured image

Set poster to show a featured image before playback starts; without one, a video frame is used ( firstFrame ). The whole surface is click-to-play.

Sources

sources accepts a plain URL or a list of ShipVideoSource objects for format fallbacks, quality variants ( height ) and per-language variants ( lang ). URLs ending in .m3u8 stream through the built-in MSE engine with adaptive bitrate; live playlists get DVR scrubbing, a LIVE badge and go-to-live.

Pre-roll ads

ad takes an inline creative ( src , skipAfter , clickThroughUrl ) or an async resolver returning one, so an ad-server integration can slot in without API changes.

Composable controls

Project sh-video-controls with any mix of sh-video-scrubber , sh-video-play-button , sh-video-volume , sh-video-time , sh-video-settings , sh-video-captions-button , sh-video-cast-button (Chromecast via the Remote Playback API), sh-video-airplay-button (Safari), sh-video-pip-button , sh-video-live-button and sh-video-fullscreen-button — or project nothing to get the full default set. Cast and AirPlay render only in browsers with an available target.

Centralized state

Every control reads and writes ShipVideoState — an injectable signal store. Provide it on a wrapper component to drive the player externally (the video editor pattern): playing.set(true) plays, currentTime.set(12) seeks.

Keyboard

Space/K play-pause, M mute, F fullscreen, arrows seek and change volume, J/L jump 10s — matching familiar player conventions. Controls stay visible while focused.
