Overview

<sh-chart-sparkline> is the first of Ship's standalone charts : one series, one SVG, no axes, no legend, no runtime dependency on the rest of Ship. It is meant for KPI tiles, table cells and list rows where a trend matters more than the numbers. It fills the width it is given and defaults to --chart-h tall.

Colors

The color input ( primary , accent , success , warn , error ) picks the matching palette shades. Every visual value is a custom property declared on the host, so a plain override on the element or a parent always wins.

Shape

curve chooses linear , monotone (smooth, never overshoots) or step . area fills under the line, dot marks the latest value. min and max pin the value axis so several sparklines share a scale.

Live data

Add animate and changes to data tween over animationDuration (300ms). The common streaming case is handled on purpose: when the oldest value is dropped and a new one is appended, the line slides one slot to the left, the dropped value leaves through the left edge and the new one arrives from the right. Appending without dropping compresses the line, any other change eases every point to its new place. Reduced motion turns it off.

Accessibility

The host has role="img" and an automatic label summarising count, range and latest value. Pass ariaLabel to describe it in your own words.

Building your own with the scales module

The math lives in @ship-ui/core/ship-chart-scales : pure functions for linear scales, nice ticks and SVG path building. Standalone charts and the composable sh-chart family both use it, and so can you.
