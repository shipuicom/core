Experimental WYSIWYG Editor

Overview

ShipEditorExp is a next-generation, signal-based, and zoneless WYSIWYG editor built from the ground up. It focuses on a clean architectural separation between the DOM, the AST (Abstract Syntax Tree), and behaviors.

Architectural Patterns

  • Behavior-Driven: Each block type (paragraph, heading, quote) is defined by a standalone behavior class.
  • Selection Service: A dedicated service manages logical and DOM selection, including locking/unlocking states.
  • Signal-Based: Fully utilizes Angular signals for reactive state management.
  • Dependency-Free: No external libraries like Prosemirror or Quill.
