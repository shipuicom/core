Slot it in

Layout components arrange what you put in them. A <sh-lo-page> takes a nav , an h1 , a p , buttons marked actions , an sh-tabs , the content, and an element marked aside — in any order — and lays them out as a page. The same goes for <sh-lo-section> , <sh-lo-setting> , <sh-lo-empty-state> , <sh-lo-toolbar> (a Gmail-style line of icon buttons grouped by sh-divider s, count/pagination marked end ), <sh-lo-stat> (label, value, delta, progress bar, sparkline, footer; give it a color for a tinted headline tile), <sh-lo-stat-ring> (a value / max drawn as a progress ring), <sh-lo-ranking> ( sh-lo-ranking-item s with a value drawn as proportional bars), <sh-lo-achievement> (a badge: icon or image medallion, title, tag, description and meta, in any color , optionally locked ), <sh-lo-inbox> (a full-page mail client: folders, sh-lo-toolbar , sh-lo-inbox-item rows and a reading pane), <sh-lo-table-view> (a full-page data view: header, filters, bulk-action toolbar, a table that scrolls under its sticky header and a footer), <sh-lo-details> ( sh-lo-detail rows of dt + value) and <sh-lo-timeline> ( sh-lo-timeline-item s with a marker, title, time ).

Spacing

The outer rhythm (page padding, gaps between sections, header spacing) is owned by the layout, so content never needs margins. Inside your own content use the spacing scale: --space-1 (4px) … --space-8 (64px), and override a layout's rhythm through its variables ( --page-gap , --section-gap , …).

Variants

Every layout takes a variant and a project-wide default can be set in ShipConfig ( {{ "{ layoutSection: { variant: 'type-b' } }" }} ). sh-lo-page : type-b divides the header, type-c is flush (no padding). sh-lo-section : type-b is boxed (own surface, divided header), type-c puts title and description in a left column. sh-lo-setting : type-b stacks the control under the label, type-c is compact without dividers. sh-lo-empty-state : type-b has a dashed outline, type-c is a compact inline row. sh-lo-toolbar : type-b boxed, type-c divided. sh-lo-stat : type-b icon tile beside the text, type-c flush (no padding, chart bleeds to the edges), type-d highlighted in its color for the headline metric. sh-lo-stat-trend : type-b chart beside the text, type-c plain surface without the wash. sh-lo-stat-goal : type-b ten-segment bar, type-c compact without a card. sh-lo-stat-ring : type-b large ring with the label underneath, type-c compact inline row without a card. sh-lo-ranking : type-b bar as a tinted background behind the row, type-c dense divided rows without bars. sh-lo-achievement : type-b horizontal row, type-c compact pill for rows of earned badges. sh-lo-inbox : type-b list and reader as separate cards with two-line rows, type-c compact rows without avatars. sh-lo-table-view : type-b toolbar, table and footer inside one card, type-c flush (no page padding). sh-lo-details : type-b stacked pairs in a grid, type-c compact. sh-lo-timeline : type-b no connecting line, type-c compact.

Sizes

<sh-lo-page size="small"> (720px) for forms and settings, default (1200px) for most pages, large (1440px) for dense dashboards, or class full for no limit. The aside column drops below the content under 1024px; add class sticky to pin it.
