Purpose

Entry for the 4–8 character codes sent by email or SMS (one-time passwords, 2FA, magic codes). Typing jumps to the next box, backspace steps back, arrow keys move around, and a paste or OS autofill into any box spreads the code across the rest.

Forms

The code input is driven by the native <input> you project into it, so it supports [(ngModel)] , reactive [formControl] and signal forms [formField] out of the box. See the Signal Forms example .

Shape

length sets the number of boxes, type switches between numeric (numeric keyboard on mobile) and alphanumeric , and groupSize adds a visual gap every n boxes. Set divider to render text in that gap, or project <ng-template shCodeInputDivider> for custom content such as an icon.

Directive

The behaviour lives in [shCodeInputGroup] . Put it on any element wrapping your own inputs — for example a row of sh-form-field s — to get the same keyboard and paste handling with custom markup.
