Developer tools

The package ships an MCP server so AI agents know the components, editor snippets for every component, and four command-line tools.

MCP server

The Model Context Protocol server gives AI agents the component list, their inputs, outputs and tokens, so they write ShipUI correctly instead of guessing. It runs from the package with one command:

Cursor
  1. Open Settings › Models › MCP.
  2. Click + Add new MCP server.
  3. Name ShipUI, type command, command npx @ship-ui/core ship-mcp.
Antigravity
  1. Open your workspace or global configuration.
  2. Add @ship-ui/core to the mcpServers list, or run it with the command above.

Agents get these tools:

search_componentsFind components by name or selector.
get_component_detailsInputs, outputs, methods, CSS variables and examples for one component.
get_setup_instructionsInstallation and setup steps.
get_design_tokensPalettes, type scale, shapes and utility classes.
get_css_variable_abbreviationsThe naming scheme behind tokens like --btn-c-h.
get_icon_guideIcon usage and the ship-fg CLI.

Command-line tools

CommandWhat it does
ship-fgBuilds an icon font holding only the Phosphor icons your templates use.
ship-stylesTurns a ship-config.json / ship-styles.json into the @use … with (...) block. See Theming & styles.
ship-migrateRewrites a release's renames in your templates and styles. See Upgrading.
ship-mcpRuns the MCP server above.

Icon font setup

ship-fg scans your sources and writes a subset font plus ship.css. Run it once for builds and in watch mode next to the dev server, and load the stylesheet in index.html. The Icons page covers sizes, colours and weights.
