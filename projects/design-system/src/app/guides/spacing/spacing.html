Spacing & density

Two custom properties set the density of the whole library. Every component's padding and every gap is a tier of that pair, so one change makes an app tighter or airier, and any component can still be tuned on its own.

Set the density

The pair feeds eight tiers per axis. Tiers round to a 2px grid at any density, so borders and text stay crisp:

@for (t of tiers; track t.tier) { }
TierVerticalAt 8pxHorizontalAt 12px
--pad-y-{{ t.tier }} / --pad-x-{{ t.tier }} × {{ t.y }} {{ t.yPx }}px × {{ t.x }} {{ t.xPx }}px

Gaps

Gaps follow the same pair, per axis: a row gap (between stacked items) is a --gap-y-N tier of --pad-y, a column gap (between items side by side) a --gap-x-N tier of --pad-x. At the default pair both equal the --space-N step, so the scale reads the same; only the density moves it.

@for (t of gaps; track t.tier) { }
TierRowsAt 8pxColumnsAt 12px
--gap-y-{{ t.tier }} / --gap-x-{{ t.tier }} × {{ t.y }} {{ t.yPx }}px × {{ t.x }} {{ t.xPx }}px
